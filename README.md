# 23110235_ Phạm Võ Nhất Kha

Bài thực hành lập trình Web 26/09/2025

**Mô tả bài tập:**
Cho 01 database gồm các bảng:

* **Category**(id, name, images)
* **User**(id, fullname, email, password, phone)
* **Product**(id, title, quantity, desc, price, userid)

Trong đó, hai bảng **Category** và **User** có mối quan hệ *nhiều-nhiều*.

---

## Yêu cầu

### 1. Tìm hiểu GraphQL

Tham khảo tài liệu trong file đính kèm:
[05_GraphQL.pdf](https://utexlms.hcmute.edu.vn/pluginfile.php/1125521/mod_assign/intro/05_GraphQL.pdf)

### 2. Viết API bằng **GraphQL + Spring Boot 3** xử lý các chức năng sau:

* Hiển thị tất cả **Product** có `price` từ thấp đến cao.
* Lấy tất cả **Product** của 01 **Category**.
* Thực hiện **CRUD** cho bảng **User**, **Product**, **Category**.

### 3. Frontend

* Sử dụng **AJAX** để render dữ liệu từ API GraphQL lên trang view `.jsp` hoặc `.html`.
